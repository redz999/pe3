# PE3 Generator

Прототип десктоп-приложения для генерации перечней элементов по ГОСТ 2.701-2008
на основе BOM-файла из Altium Designer.

## Текущее состояние

На текущем этапе зафиксированы требования, архитектура и дорожная карта MVP.
Реализация интерфейса и генератора документов будет выполнена на следующих шагах.

## Подтверждённые входные данные

- Формат BOM: `xlsx` (один лист).
- Обязательные колонки:
  - `Designator`
  - `Part Number`
  - `Quantity`
- BOM не содержит объединённых ячеек, формул и скрытых строк.

## Подтверждённые выходные данные

- Генерация документа перечня элементов на основе Word-шаблона из 3 листов:
  1. Первый лист: титульная часть + начало таблицы элементов.
  2. Второй лист: продолжение таблицы элементов (тиражируемый шаблон страницы таблицы).
  3. Третий лист: лист регистрации изменений (всегда последний, не изменяется по структуре).
- При переполнении таблицы создаются дополнительные листы между первым листом и листом регистрации изменений.
- Экспорт результата: `DOCX` и `PDF`.

## Бизнес-правила (MVP)

- В перечень включаются все строки BOM.
- Группировка по позиционному префиксу (`R`, `C`, `U` и т.д.).
- Сортировка в естественном порядке (`R1, R2, R10`).
- Схлопывание последовательностей подряд при одинаковом `Part Number`
  (например, `R1-R13`).
- Обязательные поля перечня:
  - Поз. обозначение
  - Наименование
  - Кол.
  - Примечание

## Платформа

- Целевая ОС: Windows 10/11.
- Язык интерфейса: русский.
- Целевое офисное окружение: Office 2003 и новее.
