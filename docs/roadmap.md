# Дорожная карта реализации (MVP)

## Итерация 1 — Каркас и BOM-ядро

- Создать структуру решения (UI + Application + Domain + Infrastructure).
- Реализовать чтение BOM из `.xlsx`.
- Реализовать валидацию обязательных колонок.
- Реализовать группировку по префиксу и естественную сортировку.
- Реализовать объединение диапазонов по одинаковому `Part Number`.
- Покрыть модульными тестами правила обработки обозначений.

## Итерация 2 — Генерация DOCX

- Подключить Word-шаблон из 3 листов.
- Реализовать заполнение реквизитов (ФИО, проект).
- Реализовать вставку строк таблицы элементов.
- Реализовать расширение документа добавочными листами между первым и последним.
- Сформировать отчёт об ошибках генерации.

## Итерация 3 — Профили и экспорт PDF

- Реализовать хранение профилей схем (JSON).
- Реализовать UI управления профилями.
- Реализовать экспорт PDF.
- Добавить журнал выполнения для диагностики.
- Провести пользовательскую проверку на реальных BOM/шаблонах.

## Версия после MVP (Backlog)

- Фильтры исключения отдельных категорий элементов.
- Пакетная обработка нескольких BOM.
- Шаблоны с пользовательскими правилами маппинга полей.
